# Public release checklist

- [ ] README points to the final public GitHub repository; latest release assets exist.
- [ ] Tests pass on Linux, Windows, Intel macOS and Apple Silicon macOS.
- [ ] GUI opens on Windows and macOS; media layouts, Dashboard manual refresh and keyboard navigation checked.
- [ ] CDX resumes after interruption and the snapshot inventory remains complete.
- [ ] Previously failed captures remain recoverable after real Wayback outages.
- [ ] Schema-9 project backup/restore verified; schema-13 unsupported warning documented.
- [ ] Signed artifacts verified where signing is enabled; SHA-256 sums match.
- [ ] Long-run live indexing/downloading performance checked independently from localhost tests.
