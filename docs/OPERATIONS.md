# Operations

Archive Scout exposes the following project operations through the existing interface:

- Index, download, scan, and report
- Index, download, scan, then download external embedded media
- Index URLs only
- Download and scan pending URLs
- Resume interrupted work
- Rescan existing downloads with selected keyword sets
- Retry only errored URLs
- Regenerate reports only
- Check project integrity
- Repair project and rebuild indexes
- Create project backup
- Export diagnostic package
- Import an existing archive folder
- Index and download selected media
- Index media URLs only
- Download pending media
- Retry only errored media
- Run archive recovery and analysis
- Rebuild forum threads only
- Merge another Archive Scout project

AI relevance review is started from its own page after a completed scan rather than being hidden inside the normal scan operation. This keeps network/API cost explicit and keeps deterministic scan completion independent of AI availability.
