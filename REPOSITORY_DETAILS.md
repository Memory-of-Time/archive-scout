# Repository details

Project: Archive Scout
Release: 1.0.0
Project schema: 11
Python: 3.11+
License: MIT

Archive Scout is a cross-platform GUI and CLI research workspace for public Wayback Machine captures. SQLite is the authoritative manifest, queue, coverage, classification, scan/review, and recovery store.

The 1.0.0 source tree includes explicit Windows DPI metadata, cross-platform packaging scripts, offline/unit/integration tests, resumable Wayback request control, deterministic scanning, report/export tooling, Research Intelligence, and optional AI relevance providers.

Pre-release serialized version identifiers remain recognized only as migration inputs for existing project folders.
