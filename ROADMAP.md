# Archive Scout roadmap

Archive Scout 1.0 establishes the stable project format, desktop interface, deterministic archive research workflow, external-media pipeline, optional AI relevance layer, and project recovery foundation.

Future work should remain conservative and compatibility-first.

## Near-term priorities

- Continue measuring large-project memory, database, and UI behavior on real multi-million-capture projects.
- Expand archive-policy diagnostics when Wayback exposes additional machine-readable failure reasons.
- Improve AI candidate budgeting and cost estimates without changing deterministic search behavior.
- Add optional model presets and clearer per-run token/cost reporting when reliable API usage metadata is available.
- Continue strengthening external-media discovery for historically important player formats and uncommon lazy-loading conventions.
- Improve report navigation and evidence comparison for large AI relevance runs.

## Longer-term possibilities

- Optional local semantic pre-ranking when a lightweight cross-platform model can be packaged without compromising startup reliability or dramatically increasing download size.
- Pluggable relevance providers behind the existing AI result schema.
- Richer relationship visualization for mirrors, first appearances, and reconstructed forum threads.
- Additional archive providers where their access policies and APIs permit a comparable resumable research workflow.

Major changes should preserve project migration, deterministic reproducibility, rate-limited archive access, and human review as core design requirements.
