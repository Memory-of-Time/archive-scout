# Archive Scout roadmap

Core priorities are completeness, restartability, verifiable capture retention, and stable long-running operation. Changes should avoid reindexing existing projects without necessity or weakening the text/media classification policy.

Areas for continued verification include large-project retry fairness, native Windows/macOS packaging, real Wayback outages, and multi-day memory/throughput behavior. Benchmarks must distinguish local fixtures from live Internet Archive availability.
